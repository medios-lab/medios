# docs/research/agents

Research notes on agentic infrastructure outside the medios tree itself —
how other substrates model agents, and what that implies for medios.

- `infra/` — substrate positioning: comparisons of agent execution
  substrates (edge isolates, resource brokers, container farms) and the
  primitives each one owns.

Notes here follow the same format as `docs/research/`: hypothesis or
question, evidence, implication for medios, references. Experiments with
code stay in `docs/research/` proper, next to their sources.
